# Hinário

Hinário para uso offline: hinos de adoração e louvor, organizados por número e em ordem alfabética.

🔗 Acesse em **https://rafa-mkr2.github.io/hinario/**

## Funcionalidades

- Todos os hinos em uma única página, prontos para uso offline
- Navegação **por número** (123) e **por ordem alfabética** (ABC)
- Layout responsivo e acessível (navegação por teclado, foco visível, tema com contraste)
- Sem dependências externas: JavaScript puro + CSS moderno (substituiu o jQuery/Materialize)
- Impressão amigável e respeito à preferência de movimento reduzido

## Desenvolvimento

Abra o `index.html` diretamente no navegador ou sirva a pasta com um servidor estático:

```bash
python3 -m http.server
```
